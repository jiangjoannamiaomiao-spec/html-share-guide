情绪拆解方法论

热点不能直接变成商品，中间必须经过一层翻译——情绪。这是探针把"市场在发生什么"翻译成"名创该做什么"的学理底座：可定义、可测量、可追踪、可落到符号与商品。

L0为什么要拆情绪

情绪本身不能被购买，但情绪驱动购买决策。所以从"热点"到"商品"，情绪是绕不开的翻译层——先把热点归因到情绪，再把情绪拆成可被商品承载的符号。

L1学理地基 · 效价-唤醒环形模型

心理学公认框架（Russell, 1980）：任何情绪都能定位在两条轴上——效价(积极↔消极) × 唤醒度(高↔低)。这给了情绪一个"坐标系"，让原本玄乎的情绪变得可比较、可量化。两份行业报告的情绪模型都建在此之上。

L2情绪来源三层 · 对应底色/季节/事件

情绪按"为什么产生"分三层来源（睿丛框架），正好对应我们的三层时间结构——决定一个情绪是长青底色还是窗口期机会。

超越性情绪
面对宏大/抽象：认同感·敬畏感·探秘感·伤逝感
社会适应性情绪
成就/影响力/关系三组张力：希望感·比较感·归属感·焦虑感
生存适应性情绪
最底层最稳定：快乐·愤怒·悲伤·恐惧·惊讶·厌恶
生存适应性→底色层 · 长期不变（悦己/治愈）
社会适应性→关系/季节层 · 中周期、需被接住
超越性→文化/事件层 · 事件触发、短周期

→ 底色情绪适合做长青产品线；季节/事件情绪适合提前卡窗口。这一层决定机会卡的"保质期"。

L3颗粒度 · 从 3 层细到 95 个情绪

L6双坐标定位 · 机会卡的精华

一个 IP 不是一个点，而是三个坐标的交叉——同时回答"什么情绪质地、能火多久、信号多强"。这三轴一锁定，机会卡的判断就立起来了。

Axis 1 · 质地
效价-唤醒
它是哪种情绪？落在四象限的哪个位置（治愈/爽感/共情…）。
Axis 2 · 时长
时间层
底色/季节/事件——决定它是长青线还是窗口期机会。
Axis 3 · 强度
浓度 / 增速
情绪浓度 + 声量同比/环比——升势、见顶还是起量。
