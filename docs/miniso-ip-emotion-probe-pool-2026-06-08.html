情绪九宫格

情绪格子图：谁占了哪一格，空白处就是机会

把潮玩 IP 按情绪定位到格子里——看哪些情绪格还没被占＝名创的白空间机会。两个坐标：效价＝情绪的"正负"（积极 ↔ 消极），唤醒度＝情绪的"强弱 / 激动程度"（高 ↔ 低）；两者一组合，就能把任何情绪定位到一个象限（Russell 效价-唤醒模型）。

注：当前各 IP 站位为初步判断（基于公开资料一阶近似），尚未用真实内容跑 95 类校准——严谨做法＝取内容 → 语义聚类 → 对照 95 类打标 → 情绪浓度加权 → 落坐标。
