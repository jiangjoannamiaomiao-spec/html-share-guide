HTML 一键分享工作流

一行命令建项目、AI 写 HTML、自动 push 到 GitHub Pages，几分钟拿到可分享链接。基于 macOS + Claude Code/Codex + GitHub Pages。

TL;DR

newproject 项目名 --pages 建项目 → 进 AI 写 HTML → AI 自己 push → 1-2 分钟拿链接发同事。不用记命令、不用碰网页、不用配置部署。

1这套方案能做什么

输入：一句话需求（"做个 XX 网页"）

输出：一条公开访问的链接，同事点击就能看。

链接格式：https://<用户名>.github.io/<项目名>/

2一次性环境准备 (~20 分钟)

装 GitHub CLI 并登录

brew install gh
gh auth login
gh auth refresh -h github.com -s repo,workflow

配 git 全局身份

git config --global user.name "<你的 GitHub 用户名>"
git config --global user.email "<你的 GitHub 邮箱>"

把 ~/.local/bin 加进 PATH

echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

安装 newproject 脚本

完整脚本请联系作者获取（约 100 行）。装好后 chmod +x ~/.local/bin/newproject 即可使用。

3日常使用

第一步：建项目

newproject q3-sales-report --pages

自动建本地目录 + GitHub 仓库 + 开启 Pages。

第二步：进项目用 AI 写内容

cd ~/Documents/Github/q3-sales-report
claude    # 或 codex
"把 docs/index.html 改成 Q3 销售汇报，包括核心数据卡片、趋势图、TOP 3 客户案例。风格现代简洁，做完 commit & push"

第三步：等 1-2 分钟拿链接

https://<用户名>.github.io/q3-sales-report/

发同事即可 ✨

4命令速查

命令用途
newproject 名字私有仓库
newproject 名字 --public公开仓库
newproject 名字 --pages公开 + 自动开 Pages ⭐
newproject 名字 --no-remote只本地

5整体流程

你的需求（一句话）
↓
newproject 项目名 --pages
↓
本地目录 + GitHub 仓库 + Pages 部署（一键完成）
↓
进 claude / codex 写 HTML
↓
让 AI 自己 commit & push
↓
等 1-2 分钟
↓
拿到链接发同事 ✨

6常见坑

坑解决
HTML 必须放 docs/index.htmlPages 只支持根目录或 /docs
资源用相对路径./images/x.png，不要 /images/x.png
视频不能传 PagesPages 只支持静态文件，用外链
--pages 必须 publicprivate 仓库要 Pages 需 GitHub Pro
第一次部署慢首次 1-2 分钟，之后 20-30 秒
改完没看到更新浏览器强刷 Cmd+Shift+R

7一句话学会

newproject 项目名 --pages 建项目 → cd 进去开 AI → 自然语言告诉 AI 要什么 → AI 自己 push → 1-2 分钟拿链接发同事。

不用记命令、不用碰网页、不用配置部署。
