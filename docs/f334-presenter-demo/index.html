F-334 · 投屏演示者模式里有 demo 动画就「操作不了」

同事反馈问题的复现 + 修复对照（用桌面 Chrome / Edge 打开，会用到弹窗）
修复前

复现 Bug ▶

投屏放映窗里点进 demo 后键盘失灵，而放映窗只有「✕ 关闭」、没有翻页按钮 = 卡死。
修复后

已修复 ▶

放映窗底部新增 ‹上一页 / 下一页› / ✕ 控制条，用鼠标点就能翻页，与 demo 抢不抢焦点无关。
怎么测（每页打开后，按页面上的步骤）：
按 P 进演示者 → 点 📺 放映窗 开观众窗 → 在观众窗翻到第 2 页 demo → 点进 demo（键盘被 iframe 吃掉，两版都一样，是浏览器标准行为）→ 看观众窗底部：修复后有翻页控制条能点，修复前没有。
说明：键盘焦点进了 demo 就归 demo（不抢交互 demo 自己的方向键/空格）——所以修复点是屏上控制条，鼠标永远能翻页。放映窗用到 window.open，浏览器若拦弹窗允许一次即可。
